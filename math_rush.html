Welcome to Math Rush!

About the Game

Math Rush is an exciting and fast-paced game that challenges your arithmetic skills. Solve as many math problems as you can before time runs out!

How to Play

  1. Start the game by clicking the "Start" button.
  2. Solve the math problems that appear on the screen as quickly as possible.
  3. Each correct answer earns you points, while incorrect answers will cost you time.
  4. The game ends when the timer reaches zero. Try to beat your high score!
